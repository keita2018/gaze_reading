# 公開データ二次解析に関する確認依頼テンプレート

件名：公開・匿名化済み視線データの二次解析に関する倫理審査上の扱いの確認

指導教員／倫理審査担当者　様

現在、ACM IUI 2027への投稿を予定している研究について、所属機関における倫理審査上の扱いを確認したく、ご相談いたします。

本研究では、新たな参加者募集・実験・介入は行わず、研究目的で公開されている以下の匿名化済みデータセットのみを二次解析しています。

- ZuCo 2.0
- OneStop
- WebQAmGaze

実施内容は、公開済みの視線座標・AOI・課題ラベルを用いた機械学習および統計解析です。元データから個人を再特定する試みは行わず、論文では集約結果のみを報告します。各データセットの原著論文には、元研究における参加同意および倫理手続の説明があります。

IUI投稿時には、公開データの二次解析について、著者所属機関における審査不要、免除、既存承認の範囲内などの判断を、査読者向け非公開欄へ記載する必要があります。

つきましては、今回の研究が本学・本研究科では次のどの扱いとなるかをご確認いただけますでしょうか。

1. 新たな倫理審査は不要
2. 倫理審査の免除・簡易確認が必要
3. 既存の承認範囲に含まれる
4. 新規申請が必要
5. その他

必要な資料や手続があれば、すぐに提出いたします。
